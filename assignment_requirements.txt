Extra features I’d suggest:

- Teacher override: edit AI marks and feedback before publishing.
- Review queue: low-confidence OCR or grades go to the top.
- Deadlines and late-submission flags, plus resubmission rules.
- Notifications by email when marks are published.
- More file types: DOCX, TXT, HEIC (iPhone photos) and multi-image uploads (one assignment as several photos), and a size limit per file.
- Privacy: student data and handwriting are personal, so use encrypted storage, role-based access and a retention policy.

- Handwriting OCR 70-90%: Computer reads typed text at ~99%. Handwriting is messy, so it misreads 10-30 words out of 100. Fix: if reading is unclear, website flags it yellow for teacher to check manually.
